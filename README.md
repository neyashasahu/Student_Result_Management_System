# Student Result Management System

A simple Python-based Student Result Management System that helps manage student records and calculate grades.

## Features

- Add Student
- View Students
- Search Student
- Delete Student
- Calculate Grade
- Store Data using File Handling

## Technologies Used

- Python
- File Handling
- Functions
- Loops
- Conditional Statements

## Project Structure

```text
Student_Result_Management_System/
│── main.py
│── project.py
│── students.txt
│── README.md
```

## How to Run

1. Open the project in VS Code.
2. Open the terminal.
3. Run:

```bash
python main.py
```
